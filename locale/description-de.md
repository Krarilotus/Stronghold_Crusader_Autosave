# Autosave

Hebt die neuesten automatischen Spielstände aus Einzelspielerpartien und Wiederherstellungskopien bereits gespeicherter Karten auf. Schalte unter „Speichern“ das automatische Speichern ein oder aus. Klicke auf das Minutenfeld, gib das Intervall ein und drücke Enter. Nutze unter „Laden“ oder „Speichern“ den Papierkorb zum Verwerfen, den gebogenen Pfeil zum Wiederherstellen oder „Ordner öffnen“, um deine Dateien zu finden.
