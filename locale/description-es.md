# Autosave

Conserva los últimos autoguardados de partidas de un jugador y copias de recuperación de mapas con nombre. En Guardar, activa o desactiva el autoguardado, o haz clic en el campo de minutos, escribe el intervalo y pulsa Enter. En Cargar o Guardar, usa la papelera para descartar archivos, la flecha curva para restaurarlos o Abrir carpeta para localizarlos.
