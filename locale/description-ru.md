# Autosave

Автоматически сохраняет вашу одиночную игру каждые несколько минут и хранит несколько последних автосохранений. Также может хранить копию автосохранения для карт с именем, пока вы их редактируете. Кнопки в окнах загрузки и сохранения позволяют удалить сохранение или карту, восстановить удалённый файл или показать выбранный файл в папке.
