# Autosave

Хранит сменяемые автосохранения для одиночных игр и резервные копии названных карт. В окне «Сохранить» переключите автосохранение или нажмите на поле минут, введите интервал и нажмите Enter. В окнах «Загрузить» и «Сохранить» используйте корзину для сброса, изогнутую стрелку для восстановления или «Открыть папку» для доступа к файлам.
