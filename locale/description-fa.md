# Autosave

ذخیره‌های خودکار چرخشی برای بازی‌های تک‌نفره و نسخه‌های بازیابی برای نقشه‌های نام‌گذاری‌شده نگه می‌دارد. در بخش ذخیره، ذخیرهٔ خودکار را روشن یا خاموش کنید یا روی کادر دقیقه کلیک کرده، فاصله را وارد کنید و Enter بزنید. در بخش بارگذاری یا ذخیره، از سطل زباله برای کنار گذاشتن، از پیکان خمیده برای بازیابی و از «باز کردن پوشه» برای یافتن فایل‌هایتان استفاده کنید.
